# Pacote para o advogado e o dono: perguntas em aberto do WorkEasy

> **Rascunho para revisão. Não é parecer jurídico. Cada ponto precisa da confirmação de um advogado ou do dono.**

Consolidado em 2026-11-09 a partir de `apps/web/docs/juridico/`: documentos 01 a 11 e `MATRIZ_CONSELHOS.md`. O arquivo `07-registro-das-operacoes-de-tratamento.csv` não foi lido.

Convenções:
- Ordem de risco: alto, médio e baixo.
- "O que o app faz hoje" traz o caminho do código (a partir de `apps/web/`) quando foi conferido nesta data. Quando a informação vem só de um rascunho, a célula diz "(rascunho)".
- Itens marcados com † são sugestões de prazo ou valor sem norma por trás (ver `02`, seção E).

## Como ler este pacote

- **Tabela A.** Perguntas para o advogado, por risco. Cada pergunta aparece uma vez. A coluna de documento lista todas as seções que tratam dela.
- **Tabela B.** Decisões do dono (produto e comercial). Não são perguntas de direito.
- **Tabela C.** Itens que os rascunhos já respondem, com a fonte.
- **Seção D.** Divergências entre documentos, e entre documentos e código, a resolver antes de publicar.
- **Seção E.** Limites deste trabalho.
