# RIPD — Work Easy

Processamento efêmero em memória RAM (Art. 11 LGPD) e consulta booleana de antecedentes.

> **Aviso (protótipo).** Este texto descreve a intenção do protótipo `services/api`, não uma conformidade verificada. Na
> prática: as imagens de documento e selfie são enviadas à API Gemini (Google), um operador terceiro, sem contrato nem
> avaliação de transferência internacional registrados aqui; a "consulta de antecedentes" **não existe** (o protótipo
> devolve sempre revisão manual); e "descarte em RAM" só significa que o servidor não grava as imagens. Este rascunho não
> é um RIPD completo nem parecer jurídico.
